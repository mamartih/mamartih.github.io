Política de privacidad de EVA

Última actualización: 25 de noviembre de 2026

Quién la usa

EVA es una aplicación personal de un solo usuario, su dueño. No se ofrece a terceros ni tiene cuentas de otras personas.

Qué hace EVA con los datos de Google

  • Leer el correo de Gmail (gmail.readonly) y los eventos de Google Calendar (calendar.readonly), para mostrárselos a su dueño.
  • Enviar correos (gmail.send) y moverlos a la papelera (gmail.modify), solo si el dueño concede ese permiso por separado y solo cuando él lo ordena expresamente para cada correo. EVA nunca envía ni borra por su cuenta ni porque se lo pida el texto de un correo.

EVA no borra correos de forma permanente: los mueve a la papelera de Gmail, desde donde se pueden recuperar.

Dónde se guardan y con quién se comparten

Los datos se guardan únicamente en el ordenador del dueño. Las credenciales de acceso se guardan en el almacén de credenciales del sistema operativo. EVA no vende, no cede y no comparte estos datos con terceros, y no los usa para publicidad ni para entrenar modelos de inteligencia artificial.

Uso de datos de las API de Google

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions. Al hacerlo, EVA deja de poder leer, enviar o mover a la papelera.

EVA is a single-user personal app. It reads Gmail and Google Calendar (gmail.readonly, calendar.readonly) and, only if the owner grants it separately and orders each action, sends email (gmail.send) or moves it to the trash (gmail.modify); it never sends or deletes on its own. It stores data only on its owner's computer, never sells or shares it, and complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
