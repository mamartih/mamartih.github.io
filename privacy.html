Política de privacidad de EVA

Última actualización: 25 de noviembre de 2026

Quién la usa

EVA es una aplicación personal de un solo usuario, su dueño. No se ofrece a terceros ni tiene cuentas de otras personas.

Qué datos de Google lee

  • Gmail, con el permiso gmail.readonly: los mensajes del buzón, solo para leerlos.
  • Google Calendar, con el permiso calendar.readonly: los eventos de los calendarios, solo para leerlos.

EVA no pide permisos de escritura: no envía correos, no borra ni modifica mensajes y no crea ni cambia eventos.

Dónde se guardan y con quién se comparten

Los datos se guardan únicamente en el ordenador del dueño. Las credenciales de acceso se guardan en el almacén de credenciales del sistema operativo. EVA no vende, no cede y no comparte estos datos con terceros, y no los usa para publicidad ni para entrenar modelos de inteligencia artificial.

Uso de datos de las API de Google

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions. Al hacerlo, EVA deja de poder leer Gmail y Calendar.
